# AI Job Tracker — frontend

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · recharts · dnd-kit.

```bash
cp .env.example .env.local
npm install
npm run dev        # http://localhost:3000 (expects the API on :8000)
npm run lint && npm run typecheck && npm run build
```

See the [root README](../README.md) for architecture, deployment and environment variables.
